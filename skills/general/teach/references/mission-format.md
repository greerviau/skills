# MISSION.md format

```md
# Mission: {topic}

## Why
{The concrete outcome the user wants, in 1-3 sentences.}

## Success looks like
- {A specific thing the user can do}

## Constraints
- Teaching style: {how the user prefers to be taught}
- {Time, tools, other limits}

## Out of scope
- {Adjacent topics to skip for now}
```
