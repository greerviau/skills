# Learning record format

File name: `learning-records/NNNN-slug.md`, numbered from `0001`.

```md
# {What was learned or established}

Reviewed: {YYYY-MM-DD}

{1-3 sentences: what the user demonstrated, the evidence, and what it changes about the next session.}
```

To supersede a record, add `Status: superseded by NNNN` on the line after `Reviewed:`.
